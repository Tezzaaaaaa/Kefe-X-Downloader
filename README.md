# Kefe X Downloader

A lightweight, standalone utility designed to help users archive media from supported platforms for personal offline viewing.

## Features

- **Supported Platforms:** Retrieve media from various supported websites. *(Note: Check the docs for the full list of supported sites).*
- **Quality Selection:** Choose your preferred video resolution and format before downloading.
- **User-Friendly Interface:** Simple CLI (Command Line Interface) / GUI (Graphical User Interface) for easy operation.
- **No Hosting:** This tool only facilitates the download of media directly from the source to your local machine. We do not host, upload, or distribute any content.
- **Lightweight:** Minimal dependencies and fast execution.
